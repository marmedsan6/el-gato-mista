# Memoria del proyecto

Memoria compartida para cualquier agente. Va en git; nunca lleva claves ni datos personales.

| Fichero | Qué guarda | Formato |
|---|---|---|
| `decisiones.md` | Decisiones de Mario y por qué | `- AAAA-MM-DD · decisión — motivo` |

- Las decisiones grandes tienen además un ADR en `docs/decisiones/`.
